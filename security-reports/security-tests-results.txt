Sotufab security-control tests - production demo database
========================================================
Run date: 2026-11-26
Database: odoo17 (Odoo 17)
Scope: eight authorized functional/defensive checks using only the dedicated
test.sec.caissier, test.sec.clientA, and test.sec.clientB accounts.

Test results
------------
1. Authentication and POS session lifecycle: PASS
   Login/logout was exercised for the test cashier and client. POS session 20
   on configuration Shop was opened and closed; no active session remained.
2. OTP/QR: PASS for legitimate validation; PARTIAL for replay protection.
   The legitimate signed OTP/QR was accepted. An OTP allowed to expire for
   more than 60 seconds was rejected and logged as otp_expired. PIN and OTP
   failures were rejected and logged as pin_failed and pos_otp_failed.
   Replaying the consumed token was rejected as expired, but did not create a
   replay_blocked audit event.
3. Concurrent double-spend: PASS
   Two isolated transactions exercised the NOWAIT row-lock guard; the second
   attempt was blocked and double_spend_blocked was logged.
4. Inter-client IDOR: PARTIAL
   Client A's request for Client B's resource was rejected as Unauthorized,
   but no idor_blocked event was recorded.
5. XSS/SQLi input rejection: PASS
   The two submitted test payloads received HTTP 400 responses and produced
   two injection_blocked events.
6. Altered HMAC: PASS
   The modified QR signature was rejected and hmac_invalid was logged.
7. CIN access audit: PASS
   The authorized administrator revealed only the synthetic test client's
   CIN; cin_reveal was logged.
8. ML integrity and audit verification: PASS
   The guarded ML artifact loaded without an integrity failure. The final
   PostgreSQL audit chain and external seal both verified successfully.
